# Nox Node Server

A comprehensive authentication and relay management server built with Node.js and TypeScript, designed to handle user authentication, session management, and relay orchestration for the Nox platform.

## 🚀 Features

### Authentication & Security
- **Multi-factor Authentication (MFA)** with TOTP and email verification
- **Session Management** with secure token generation and validation
- **User Registration & Login** with password hashing
- **Email Verification** with configurable verification codes
- **Device Management** for authorized devices tracking
- **Integrity Checking** for security validation

### Relay & Server Management
- **Docker-based Relay Management** for dynamic server orchestration
- **Server Discovery & Registration** with automated health checks
- **Instance Management** for game servers and applications
- **World Management** for virtual environments
- **Notification System** for real-time updates

### Communication & Social
- **Real-time Communication** via WebSocket and Socket.io
- **User Presence** tracking and status management
- **Relationship Management** for user connections
- **Challenge System** for interactive features

## 🛠️ Tech Stack

- **Runtime**: Node.js with TypeScript
- **Database**: PostgreSQL with Prisma ORM
- **Web Framework**: Express.js
- **Real-time**: Socket.io & WebSocket
- **Authentication**: Custom JWT-like session tokens
- **Containerization**: Docker & Docker Compose
- **Email**: Nodemailer for email services
- **Security**: bcrypt for password hashing, speakeasy for TOTP

## 📦 Installation

### Prerequisites
- Node.js (v18+)
- PostgreSQL database
- Docker (optional, for containerized deployment)
- Python 3 (for Unity asset processing)

### Local Development

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd nox-node
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

4. **Set up the database**
   ```bash
   npm run generate  # Generate Prisma client
   npm run migrate   # Run database migrations
   ```

5. **Start development server**
   ```bash
   npm run dev
   ```

### Docker Deployment

1. **Build the Docker image**
   ```bash
   npm run build-image
   ```

2. **Start with Docker Compose**
   ```bash
   npm run compose
   ```

## 🔐 Authentication Flow

### Standard Login
1. User provides username/email and password
2. Server validates credentials
3. If MFA is enabled, server requests verification
4. Upon successful authentication, session token is issued

### Multi-Factor Authentication
1. **TOTP (Time-based One-time Password)**
   - Generated by authenticator apps (Google Authenticator, Authy)
   - 6-digit codes with 30-second validity

2. **Email Verification**
   - 6-digit codes sent via email
   - 10-minute expiration time

### Verification Code Flow
```typescript
// Example verification process
const verificationResult = await app.auth.verification.verifyFactorCode(user, code);
if (verificationResult.success) {
    // Proceed with login
    const session = await app.sessions.createSession(user);
}
```
